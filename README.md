# Hello.c

A simple C program that prints "Hello, World!" to the console.

## Source Code

```c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
```

Compile
```
gcc hello.c -o hello
```

Run
```
./hello
Output
Hello, World!
```

## Requirements
GCC or any C compiler
Linux, macOS, or Windows (with a C compiler installed)
